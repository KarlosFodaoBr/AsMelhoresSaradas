# 📊 Site de Exibição de Fluxograma

Este repositório contém um site simples desenvolvido apenas com **HTML**, **CSS** e **JavaScript**, criado com o objetivo de **apresentar um fluxograma já produzido previamente**.  
O site não gera fluxogramas — ele apenas **exibe** o fluxograma de forma organizada, responsiva e visualmente agradável.

---

## 📌 Funcionalidades

- Exibição do fluxograma de forma limpa e responsiva  
- Layout simples e direto  
- Possibilidade de zoom (caso implementado)  
- Scroll suave e navegação intuitiva  
- Código leve sem bibliotecas externas complexas

---

## 🛠 Tecnologias Utilizadas

- **HTML5** – Estrutura da página  
- **CSS3** – Estilização e responsividade  
- **JavaScript** – Interações básicas e controles (quando necessário)
